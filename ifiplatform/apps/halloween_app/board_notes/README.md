# Haunted notice board notes

Every `.txt` file here is one note on the board at `/halloween/board/`.

- **The file name** starts with the kind of note: `obituary_`, `warning_`,
  `rule_` or `missing_`, then a number: `warning_02.txt`. Your issue tells
  you the exact name.
- **Line 1** is the title.
- **The next lines** are the text: one to three sentences is plenty.
- **An optional last line** starting with `— ` (a long dash and a space) is
  the signature.

Example, `obituary_example.txt`:

```
Here lies printf debugging
Born 1972, died the day someone showed us the debugger. It will be missed by nobody, except at 3 a.m.
— The DevOps team
```
