# Study jokes

Every `joke_NN.txt` file in this folder is one joke (or excuse) for the
study page at `/study/`, which picks one at random on every visit, from
these files and the list in `../jokes.py`.

- One joke per file, as plain text. One or two sentences: short beats long.
- The file name is `joke_` + a two-digit number + `.txt`, like `joke_07.txt`.
- It shows exactly as written, in English or Norwegian.
- Keep it kind: no real people.
